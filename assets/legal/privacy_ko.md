# Korean Friend 개인정보처리방침

최종 수정일: 2026년 9월 23일

Korean Friend(이하 '앱')는 회원가입 없이 쓰는 AI 언어 학습 앱입니다. 앱은 이름, 이메일, 전화번호 같은 계정 정보를 받지 않습니다. 이 방침은 앱을 쓰는 동안 어떤 정보가 어디로 전송되고 얼마나 보관되는지 설명합니다.

## 1. 처리하는 정보와 목적

### 대화 내용
- 항목: 내가 입력하거나 말한 문장(음성은 글자로 바뀐 뒤), AI의 답변, 대화 설정(레벨, 언어, 주제)이 담긴 AI 지시문
- 목적: AI 답변 생성, 레벨 평가, 추천 문장과 발음 평가
- 전송: 무료로 이용하면 앱 서버(Vercel)를 거쳐 AI 제공자(현재 Groq)에게, 본인 API 키를 쓰면 선택한 AI 제공자에게 직접 보냅니다.
- 앱 서버는 대화 내용을 저장하지 않습니다. AI 제공자의 보관은 각 제공자의 정책을 따릅니다.

### 기기 ID
- 항목: 앱을 처음 실행할 때 만드는 무작위 ID(UUID). 이름이나 전화번호와 연결되지 않습니다.
- 목적: 무료 이용 일일 한도 계산, 신고 남용 방지
- 본인 API 키를 쓰는 경우에도 신고를 보낼 때는 이 ID를 함께 보냅니다.

### IP 주소
- 목적: 과도한 요청 차단(IP 단위 일일 한도)
- 앱 서버는 IP 원문을 저장하지 않고 해시(복원할 수 없게 바꾼 값)만 보관합니다. 호스팅 업체(Vercel)의 접속 기록에는 남을 수 있습니다.

### 광고 ID와 광고 관련 정보
- 앱은 Google AdMob 배너 광고를 보여 줍니다. Google은 광고 표시, 광고 측정, 부정 클릭 방지를 위해 광고 ID, 기기와 앱 정보, IP 주소 등을 수집합니다.
- Google의 처리 방식: https://policies.google.com/technologies/ads
- 광고 ID는 휴대폰 설정(개인정보 보호 > 광고 등, 기기마다 다름)에서 재설정하거나 삭제할 수 있습니다.

### 음성(마이크)
- 마이크는 음성 입력, 발음 연습, 핸즈프리 대화를 쓸 때만 켜집니다.
- 음성은 휴대폰의 음성 인식 기능(예: Google 음성 인식)이 처리하고, 앱은 바뀐 글자만 받습니다. 앱은 음성 파일을 저장하거나 앱 서버로 보내지 않습니다. 음성 인식 기능의 처리는 해당 제공자의 정책을 따릅니다.

### AI 응답 신고
- 항목: 신고한 AI 답변(최대 2,000자), 바로 앞의 내 메시지(최대 1,000자), 신고 사유, AI 제공자와 모델 이름, 앱 버전, 언어 설정, 해시 처리한 기기 ID
- 목적: 유해하거나 틀린 답변을 검토하고 개선하기 위함

### 기기에만 저장되는 정보
- 대화 기록, 단어장, 학습 기록(연속 학습일, 레벨, 미션), 설정, 본인 API 키(기기의 암호화 저장소)
- 이 정보는 앱 서버로 보내지 않습니다.

## 2. 처리 위탁과 국외 이전

아래 업체는 앱 기능을 위해 정보를 처리합니다. 모두 국외 업체이며, 앱을 쓰는 동안 인터넷(암호화된 HTTPS)으로 전송됩니다.

- Vercel Inc.(미국): 앱 서버 운영과 요청 중계. 서버 실행 위치는 싱가포르 등 사용자와 가까운 지역과 미국입니다. 항목: 대화 내용, 기기 ID, IP 주소
- Upstash, Inc.(미국): 일일 한도 카운터와 신고 저장. 항목: 기기 ID, 해시 처리한 IP, 신고 내용
- Groq, Inc.(미국): 무료 이용 시 AI 답변 생성. 항목: 대화 내용
- 본인 API 키를 쓰는 경우 선택한 제공자: Anthropic PBC(미국), Google LLC(미국, Gemini), OpenAI, L.L.C.(미국), Groq, Inc.(미국). 항목: 대화 내용
- Google LLC(미국): AdMob 광고. 항목: 광고 ID, 기기와 앱 정보, IP 주소

국외 이전을 원하지 않으면 앱 이용을 멈추고 앱을 삭제하면 됩니다. AI 대화는 국외 전송 없이 제공할 수 없습니다.

## 3. 보관 기간과 파기

- 일일 한도 카운터(기기 ID, 해시 처리한 IP): 48시간 뒤 자동 삭제
- AI 응답 신고: 최근 2,000건까지만 보관하고, 넘으면 오래된 것부터 자동 삭제
- 전송에 실패한 신고: 기기에 최대 20건까지 임시 보관하고, 다시 보내는 데 성공하면 삭제
- 기기에만 저장되는 정보: 앱을 삭제할 때까지
- AI 제공자와 Google이 보관하는 정보: 각 회사의 정책에 따름

## 4. 삭제 방법과 이용자의 권리

- 기기에 저장된 정보 전체: 앱을 삭제하거나, 휴대폰 설정 > 애플리케이션 > Korean Friend > 저장공간 > 데이터 삭제
- 광고 ID: 휴대폰 설정에서 재설정하거나 삭제
- 서버에 남은 정보(신고 등)의 열람, 정정, 삭제, 처리 정지 요청: 아래 이메일로 보내 주세요. 앱에는 계정이 없어 요청자를 특정하기 어려우므로 신고한 날짜와 내용을 함께 알려 주세요.

## 5. 안전성 확보 조치

- 모든 통신은 HTTPS로 암호화합니다.
- 본인 API 키는 기기의 암호화 저장소에 보관하고 앱 서버로 보내지 않습니다.
- 앱 서버는 IP와 신고자의 기기 ID를 해시로만 저장합니다.
